## 2. 已确定的技术路线

用户已选择方案 1：富表格代码块。

比较过的路线：

- 富表格代码块：内容与样式完整存入笔记，可表达图片、合并结构和模板，适合本次目标。
- 标准 Markdown 表格：跨工具兼容较好，但不能完整表达高级表格结构。
- 混合模式：可兼顾普通与高级表格，转换及维护成本较高。

每张表以一个 `rich-table` 围栏代码块保存在 `.md` 文件中，内部使用带版本号的 JSON。阅读视图和实时预览显示表格，源码模式显示数据。停用插件后内容仍保留在笔记中，但呈现 JSON；导出 HTML 或 Markdown 可用于其他工具。

## 3. 用户旅程

1. 在笔记中执行“插入富表格”，选择行列数量，默认 5 行 × 4 列。
2. 笔记内出现表格预览；点击“编辑”进入较大的表格编辑窗口。
3. 输入文本，或直接粘贴 Excel 区域；通过单击选格、Shift 扩选选择区域。
4. 从工具栏或右键菜单操作行列、合并及文字格式，右侧面板选择模板并微调。
5. 点击“保存并关闭”，变更写回当前笔记的对应代码块，正文立即显示效果。
6. 再次打开继续编辑，或导出表格。

首版在独立编辑窗口完成修改，正文负责呈现和编辑入口。正文中逐格直接编辑不属于首版验收要求。

关闭未保存窗口时提供保存、放弃、继续编辑；保存失败时保持窗口和草稿。窗口内支持撤销/重做，保存前的操作不会逐次改写笔记。

## 4. 首版范围

### 表格编辑

- 文本输入，支持单元格内换行、中文输入法。
- Tab/Shift+Tab 切换单元格；Enter 进入编辑，Escape 退出当前编辑；方向键在非文本编辑状态移动选区。
- 单元格与矩形范围选择，选择整行、整列。
- 当前行上/下插入、当前列左/右插入，删除选中行列；至少保留一行一列。
- 拖动调整列宽。
- 矩形选区合并及拆分；合并时按行优先顺序保留全部内容，拆分后内容留在左上格。
- 撤销/重做覆盖文本、结构、粘贴及样式；中文组合输入作为完整编辑操作处理。

### 粘贴与图片

- Excel 区域优先解析剪贴板 HTML 表格的文本、行列及合并关系；否则解析制表符分隔文本。
- 保留空格子、中文、单元格内换行、日期显示值和前导零；默认均作为文本保存。
- 粘贴超出边界时自动扩展行列；与已有合并区域冲突时停止并提示拆分后重试。
- 不承诺完整继承 Excel 样式、公式、工作簿结构。公式接收复制时的显示值。
- 本地 PNG/JPEG/WebP/GIF 可拖入或粘贴至单元格；图片保存在 Vault 附件目录，表内记录路径、替代文本与显示宽度。
- 可调整图片宽度及移除图片引用；移除引用或撤销插入不自动删除附件文件。

### 样式

- 作用范围：整表、首行表头、当前选区。
- 字号、文字颜色、背景色、加粗、斜体、下划线、水平及垂直对齐；首版以整个单元格为单位设置。
- 边框位置、颜色、粗细、实线/虚线；隔行底色；表格标题。
- 内置基础网格、三线表、彩色表头、斑马纹、财务报表五种模板。
- 模板决定基础样式，整表覆盖其次，表头覆盖再次，单元格覆盖优先级最高。
- 切换模板保留内容、行列、合并和已有局部覆盖；“清除自定义样式”用于恢复纯模板效果。
- 使用 Obsidian 主题变量适配明暗主题；用户显式指定的颜色保持原值。

### 嵌入与导出

- 阅读视图及实时预览使用同一渲染器，隐藏编辑坐标和控件。
- 导出 HTML 保留受支持样式、合并结构及图片引用。
- 导出标准 Markdown 时舍弃样式，将合并内容置于左上格，其余位置留空，导出前说明转换结果。
- 图片导出保留文件链接，不承诺单文件嵌入图片；分享时需一并携带附件。
- 为 Obsidian 打印/PDF 提供打印样式；宿主 PDF 导出效果需要实机验证。

首版不包含公式计算、筛选分组、数据库关联、多人协作、云服务、Excel 文件读写和移动端编辑。目标先覆盖桌面 Obsidian，交付实际验证过的平台/版本记录。

## 5. 数据和模块划分

TypeScript + Obsidian 官方插件 API + esbuild；表格编辑界面使用 DOM 与 CSS，减少运行依赖。正文通过注册代码块处理器渲染；编辑窗口通过 Modal 承载。

模块分为：

- `model`：表格结构、校验、序列化、合并和行列变更，不依赖 Obsidian。
- `clipboard`：HTML/TSV 解析与导出。
- `templates`：模板及样式合成。
- `renderer`：表格视觉呈现，供正文及编辑器复用。
- `editor`：选区、输入、工具栏、右键菜单、历史记录。
- `storage`：代码块定位、冲突检测、写回与附件管理。
- `main`：插件生命周期、命令和设置。

数据包含 schemaVersion、稳定表格 ID、标题、行列 ID、列宽、各单元格文本/图片、合并跨度、模板 ID、整表/表头/单元格样式。每格都有独立记录；合并后的被覆盖格不得重复渲染。输入 JSON 不支持任意脚本或任意 HTML 执行。

内容由笔记代码块持久化，插件设置只保存默认行列数及默认模板，不保存唯一的业务数据。

## 6. 保存和异常行为

- 编辑打开时记录原代码块快照；保存时重新定位并比对该表内容。
- 活跃笔记通过 Editor 事务替换精确范围，保留笔记撤销体验；无活跃编辑器时使用 Vault 的原子处理能力。
- 文件其他位置变化不应阻止保存，目标表格有外部变化则停止覆盖，保留草稿供复制或重新打开。
- 同一文件内表格 ID 重复时，禁止猜测目标并覆盖；提供明确的重复 ID 提示。
- 解析失败或不支持的数据版本保留源码并展示错误，禁止自动替换为默认空表。
- 文件删除、重命名和保存失败必须保持草稿可取回。编辑期间跟踪文件对象和路径变化。
- 写入附件前校验格式与大小；单张上限 10 MB。校验图片路径指向 Vault 内文件。
- 首版单表最多 200 行 × 50 列；创建和粘贴都校验上限，超限时保留原表并提示。
- 粘贴 HTML 只提取允许的文本和结构，不直接注入原始 HTML，不执行事件和脚本。

## 7. 验收与交付

必测案例：

1. 创建、修改、保存、关闭笔记并重新打开，内容和样式一致。
2. 同一笔记有两张表，编辑第二张只修改第二张；表前正文变动不导致写错位置。
3. Excel 粘贴覆盖中文、空格子、前导零、多行文本、合并区域及越界扩展。
4. 合并、拆分、增删行列、撤销重做后结构合法且内容按约定保留。
5. 切换五种模板、设置局部样式后，编辑器和笔记预览一致。
6. 图片插入、重开可见、调整宽度、移除引用，附件路径持久化。
7. 外部修改同一表格时阻止覆盖；非法数据保留；取消编辑不写回。
8. 中文输入法、键盘导航、明暗主题和最大允许表格基本操作可用。
9. HTML/Markdown 导出符合已说明的保留及降级规则。

验证层次：数据操作与剪贴板解析自动化测试、TypeScript 检查与构建、隔离测试 Vault 中的 Obsidian 实机验证。浏览器模拟验证不能代替宿主验证；宿主不可用时需在交付说明中明确未验证项。

交付：源码、`manifest.json`、构建后的 `main.js`、`styles.css`、可安装 ZIP、中文使用说明、示例笔记、测试与兼容性记录。用户将插件目录放入 Vault 的 `.obsidian/plugins/obsidian-rich-table/` 后启用；是否实际安装到现有 Vault 另由用户指定位置。
