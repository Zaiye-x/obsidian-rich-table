# 实施计划

依据已批准的 2026-09-27 设计，直接实施并验证，无需再次确认。

1. 建立 TypeScript + esbuild 工程。仅打包代码与 CSS，不引入网络服务和远程字体。界面使用 Obsidian 语义颜色、清晰选区、可见焦点和中文标签。
2. 实现独立模型：合法性校验、矩形选择、合并/拆分、行列操作、历史栈；测试合并后删行等可能丢数据的边界。
3. 实现 HTML/TSV 剪贴板解析、五种模板、共用渲染器及导出。
4. 实现 Modal 编辑器：网格、文本编辑、键盘/选区、右键菜单、列宽、样式面板、图片和撤销重做。
5. 实现代码块定位、冲突保护、Editor/Vault 写回、附件及默认设置。
6. 运行类型检查、构建、自动化测试。在隔离 Vault 测试 Obsidian 的插件载入、渲染、编辑和保存；无法验证的项目据实标记。
7. 生成安装包、示例笔记、中文说明、验证记录。保留源码供后续迭代。

自动化重点是数据不丢失与精确写回；界面重点是可发现操作、中文输入和宿主适配。任何未通过项目先修复再打包。
