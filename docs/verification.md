### 浏览器开发预览

浏览器模拟宿主导入了实际 `TableEditor` 实现。已实际操作验证：

- 打开编辑窗口并展示工具栏和样式面板。
- 输入中文、多行文字。
- 用 Shift+方向键扩选，合并相邻格后保留两格文字。
- 选中 B2 后点击“新增行”，得到 B3、6 行 × 4 列；继续点击“新增列”，得到 C3、6 行 × 5 列。
- “更多”菜单可在当前选区上方插入行，插入后保持新位置高亮。
- 新增按钮在浅色和深色主题下均可见，桌面预览宽度下工具栏无溢出。

浏览器会话没有完成保存后重开、主题切换、真实系统剪贴板及图片附件全流程；不把这些项目记为通过。截图工具超时，没有可作为最终视觉验收依据的截图。

v0.1.3 的编辑器可在浏览器模拟宿主中正常打开，但浏览器自动化拖动接口只接受 HTML `draggable` 元素，无法模拟单元格的原生 pointer 框选手势。鼠标框选目前由 jsdom 中的 pointerdown、pointerover、pointerup 事件链测试覆盖，仍需在 Obsidian 中手动验收实际手感。

## 尚未完成的实机验收

本机存在 Obsidian，但 CLI 未启用，桌面自动化未能稳定取得可操作窗口，指定窗口截图超时后停止了桌面自动化。没有修改现有个人 Vault，也没有将模拟预览结果记为实机结果。

已准备独立 `test-vault` 与两张示例表。以下需要在真实 Obsidian 中验收：

1. 插件启用、左侧栏表格图标、斜杠菜单、命令插表、阅读视图和实时预览渲染、保存后关闭并重新打开。
2. Editor 事务和 Vault.process 两种保存路径，笔记重命名、外部同步冲突、保存期间删除文件。
3. 从实际 Excel 复制中文、空格子、前导零、日期、多行及合并区域。
4. PNG/JPEG/WebP/GIF 的系统粘贴、拖入、附件写入、重开、宽度调整及导出链接。
5. 实际中文输入法、宿主快捷键、焦点、列宽拖动、明暗主题与不同窗口尺寸。
6. 200 行 × 50 列时的编辑、样式变更及撤销性能。
7. Obsidian 打印/PDF 导出与第三方主题、其他表格插件的兼容性。

声明最低宿主版本 1.8.7 来源于使用的 API 类型版本，并非已测试版本矩阵。插件功能代码已实现，宿主兼容性需在上述验收后确认。
